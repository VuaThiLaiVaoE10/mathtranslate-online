# MathTranslate v2 — Academic LaTeX & Layout-Preserving PDF Translator (EN → VI)

Web workbench and batch translation pipeline for mathematical papers and textbooks:
- **ArXiv ID / Single `.tex` / Project `.zip`**: Preserves 100% of LaTeX math environments, macros, and citations.
- **PDF Document (EN → VI)**: Protects MathType, TeX, PUA, and vector equations, translates prose in resilient batches with SQLite Translation Memory, Checkpoint/Resume, and automated visual QA.
